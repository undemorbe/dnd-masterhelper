# 39. СНАРЯЖЕНИЕ И ПРЕДМЕТЫ

Предметы рассчитаны на персонажей начальных уровней. Большинство даёт небольшое преимущество, открывает взаимодействие с миром или помогает пережить конкретную ситуацию.

## Сюжетные и особые предметы

| Предмет | Где | Использование |
| **Флакон краски Сайласа** | Мастерская, чердак | 5 зарядов; дорисовать, стереть, изменить (см. раздел 3). Каждое применение — 1 Мазок |
| **Растворитель** | Кладовая пигментов | 3 применения; 2d6 урона нарисованному или стереть нарисованный объект. Растит Страх нарисованных |
| **Синий берет** | Здание 1 (Фредерик) | Надевший видит, что нарисовано: у нарисованного нет тени в синем свете |
| **Красный / зелёный перстень** | Фредерики | Ключи цветовой системы: оживить / сохранить |
| **Каменная корона** | Король Крыс | Крысы дружелюбны; 1 раз в день призвать стаю или расспросить крыс |
| **Шляпа контроля** | Броммир | 1 раз в день — «Приказ» (СЛ 12); надевший рискует сам получить приказ |
| **Половина фотографии** | Шкатулка с повозки | Крючок к Мглину; вместе со второй половиной — артефакт |
| **Фотоаппарат Аурела** | Мглин | 3 вспышки за долгую передышку; прерывание существ Скрытности, раскрытие невидимого |
| **Пустая рамка** | Мастерская / находка | Светится рядом с картинами, связанными с героями; может «поймать» мелкое нарисованное существо |
| **Именная фотография** | Селена | Иммунитет к одному провалу Забвения |

## Медицина

| Предмет | Использование |
| Бинт | Одноразовый. Остановить кровотечение; стабилизировать тяжело раненого |
| Игла и нить | Простая обработка раны; с проверкой Медицины СЛ 13 снимает малую травму «Кровотечение» |
| Флакон спирта | Обработать рану или поджечь |
| Медицинская склянка | Восстанавливает 1d4+1 хита |
| Обезболивающая настойка | Подавляет малую травму на 1 час, среднюю — на 10 минут; не лечит |
| Антисептический порошок | Против заражённых ран; преимущество на спасброски от болезни |
| Шина | Фиксация конечности: травма ноги/руки на ступень легче до лечения |
| Швейный набор | Ремонт одежды и простая обработка ран |
| Сухие травы | Настой, дым или ритуал |

## Свет и огонь

| Предмет | Использование |
| Свеча | Свет 1,5 м, 1 час |
| Чёрная свеча | Горит слабее, мерцает рядом с иллюзиями |
| Фонарь | Надёжный переносной источник света, 6 часов на масле |
| Масляная лампа | Дольше горит, требует масла |
| Флакон масла | Топливо или горючая жидкость (1d4 огня, разлить и поджечь) |
| Спички | Небольшой запас огня |
| Кремень и кресало | Надёжный способ развести огонь |

## Инструменты

| Предмет | Использование |
| Тесак мясника | Инструмент и импровизированное оружие |
| Ключ-трещотка | Простые механизмы |
| Набор отмычек | Вскрывать простые замки |
| Верёвка 10 м | Подъём, связывание, ловушки |
| Крюк-кошка | Работает вместе с верёвкой |
| Мешочек гвоздей | Ремонт, ловушки, баррикады |
| Маленький молоток | Инструмент |
| Кусачки | Проволока, тонкие цепи, кандалы-капканы карьера |
| Карманное зеркало | Наблюдать за углами, проверять отражения, обходить «Глазок» в Мглине |
| Осколок зеркала | Показывает фрагмент реальности в иллюзорной зоне |

## Письмо, ритуал, краска

| Предмет | Использование |
| Мел | Метки в лабиринтах; счёт ступеней в Мглине |
| Кусок мела с красной пылью | Заметные знаки; в цветовой системе — «красный» |
| Уголь | Знаки, быстрые записи; угольные эскизы в городе «стираются» им же |
| Перо и чернила | Письмо, символы |
| Красные чернила | Заменитель крови для некоторых загадок |
| Записная книжка | Заметки, карты, символы |
| Кусок холста | Перевязка, маскировка, живопись |
| Пустой флакон / пробирка | Образцы крови, краски, жидкости |
| Мешочек соли | Ритуалы, консервация; соль на страницах Палимпсеста |
| Мешочек железных опилок | Ритуалы; рядом с небесным железом — указывают направление к Кратеру |
| Медный колокольчик | Сигнал; иногда реагирует на сверхъестественное |
| Свисток | Дальний сигнал; прерывает «KNEEL» Короля Крыс |

## Улики и загадочное

| Предмет | Использование |
| Старый ключ | Подходит к одному неизвестному замку (канон: к Квартире 0 в Мглине) |
| Ключ без замка | Канон: открывает клетку из чёрного железа в Зверинце |
| Бирка с номером | Улика, пропуск. Канон: номер раба карьера «Глотка» — Веспера |
| Портретная карточка | Неизвестный человек. Канон: молодой Зефер Ноктрейн |
| Кусок карты | Фрагмент маршрута по городу |
| Старый дневник | Фрагменты чужих наблюдений |

## Быт

Сухой паёк, фляга воды, кружка.

# 43. ШПАРГАЛКА МАСТЕРА

| Ситуация | Правило |
| Враг начинает подготовку | Явно опишите опасность и условие прерывания; положите жетон |
| Игрок прерывает подготовку | Враг пропускает следующий ход, без реакций; союзник рядом — Удар в открытую рану |
| Выстрел во время подготовки | Спасбросок Телосложения врага против СЛ стрелка |
| Подготовленная обычная атака попала | Двойной бросок урона |
| Персонаж получил урон в ближнем бою | Возврат крови: 1d4 за попадание до конца следующего хода |
| Персонаж упал до 0 хитов | Автоматическая малая травма |
| Три травмы | 1 уровень истощения |
| Использована краска | −1 заряд, +1 Мазок |
| 3 Мазка | Башня пропускает |
| Долгая передышка в городе | +1 к Часам Холста |
| Часы Холста полны | Ночь Перекраски |
| Ушли из локации без артефакта | Часы Культа +2 |
| Провал против эмоции | +1 Отголосок; при 3 — Одержимость |
| Уничтожен нарисованный NPC | Страх нарисованных +1; Часы Холста +1 |
| Эмоция разрешена мирно | Слово Вести «чисто» + вдохновение всем |
| Эмоция разрешена силой | Слово Вести «надтреснуто» |
| Корвин рядом с Эстелом | Печать: Зуд → Жжение → Зов |
| Эстел искренне проявил чувство | Оттепель +1 |
| Велиссу отвергли | Помеха на Харизму, СЛ заклинаний −2 до короткой передышки |
| Ума отправила рапорт | Приказ командования; невыполнение — жетон Недоверия |
| Найден материал | Сохранить для улучшения |
| Оружие улучшено | Небольшой числовой рост + новое тактическое свойство |
