# Город, который нарисовали — сайт мастера

Vite + Vue 3. Методичка собирается из текстов `content/*.txt`, публикуется на GitHub Pages.

## Запуск локально

Нужен Node.js 20.19+.

```bash
npm install
npm run dev      # http://localhost:5173, правка .txt перезагружает страницу
npm run build    # сборка в dist/
npm run preview  # посмотреть собранную версию
```

## Публикация (GitHub Pages)

Workflow `.github/workflows/deploy.yml` собирает сайт и выкладывает его на Pages при каждом push в `main`
(на pull request — только проверочная сборка).

Один раз в репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Сайт использует относительные пути и hash-маршруты (`#/s12`, `#/track`), поэтому работает по адресу
`https://<user>.github.io/<repo>/` без правки конфига.

## Где хранятся заметки

Заметки к разделам, трекеры, журнал сессий, закладки, история костей и инициатива сохраняются
в `localStorage` браузера (ключи `gkn.*`): автоматически, без сервера, с синхронизацией между вкладками.
Куки не используются — их лимит ~4 КБ, заметки туда не помещаются.

Данные живут только в этом браузере на этом устройстве. Резервная копия — «Инструменты → Мои данные»:
«Сохранить в файл» выгружает JSON, «Загрузить из файла» вливает его обратно (более свежие заметки побеждают,
записи журнала объединяются). Загрузка понимает и `data/store.json` от старого локального сервера.

## Файлы

- `content/*.txt` — тексты методички (мини-разметка: `# N. Заголовок`, `##`, `! важно`, `? совет`, `% тайна`, `> цитата`, таблицы `|…|`, списки).
- `scripts/content.js` — парсер разметки; подключается в Vite как модуль `virtual:content`.
- `src/` — приложение: `store.js` (хранилище), `router.js`, `views/`, `components/`.
- `scripts/build-docx.cjs` — сборка `Методичка мастера.docx`: `npm run docx`.
