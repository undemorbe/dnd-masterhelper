# Город, который нарисовали — сайт мастера

## Запуск
- Двойной клик по **«Запустить сайт.command»**. Откроется браузер на http://127.0.0.1:8787/
- Или в терминале: `cd ~/Programming/dnd && python3 server.py`
- Остановить: Ctrl+C в окне терминала.

Если macOS не даёт открыть .command («неизвестный разработчик»): правый клик → «Открыть» → «Открыть».

## Где хранятся заметки
Заметки к разделам, трекеры, журнал сессий и закладки сохраняются в `data/store.json`.
Этот файл можно копировать для бэкапа. Если открыть `index.html` без сервера,
сайт работает, но заметки сохраняются только в браузере.

## Файлы
- `index.html` — сайт (вся методичка внутри).
- `server.py` — локальный сервер с сохранением заметок.
- `Методичка мастера.docx` — та же методичка для Word.
- `source/content/*.txt` — тексты методички.
- `source/build_site.py` — пересобрать `index.html` после правки текстов: `python3 source/build_site.py`.
- `source/build_docx.js` — пересобрать docx (нужен Node и `npm i docx`): `node source/build_docx.js "Методичка мастера.docx"`.
